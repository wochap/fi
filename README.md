# fi workspace

This repository is a virtual Cargo workspace with two Rust members:

- `crates/automerge_repo` owns the reusable Automerge repository, persistence,
  synchronization, lifecycle, protocol, transport abstractions, and their tests.
- `crates/app_core` reserves the application-backend boundary and depends on
  `automerge-repo`. It currently contains only an `AppCore` scaffold.

The dependency direction is strictly:

```text
app_core -> automerge_repo -> automerge
```

Application features—including finance domain logic, projections, identity,
pairing, discovery, platform integration, and authentication—are intentionally
deferred. The generic Repo crate must not acquire those concerns.

Run workspace checks from this directory:

```sh
cargo fmt --all --check
cargo test --workspace
cargo clippy --workspace --all-targets -- -D warnings
```

`flutter_app/` reserves the future Flutter presentation and FRB-facing location.
Flutter scaffolding is deferred because the toolchain is unavailable; no Flutter
application has been generated by this change.
